**Deep linking** allows a user to open a specific screen in your app **directly from a URL** — like `myapp://profile/123` or `https://example.com/product/45`.

It’s common in:

- Web support
- Push notifications
- External apps linking to specific content
- ***Types of Deep Linking***
    
    
    | Type | Description |
    | --- | --- |
    | **Basic (URL Schemes)** | Custom schemes like `myapp://home` for native apps |
    | **Universal/App Links** | Standard `https://` links that open your app |
    | **Web deep linking** | Especially needed when deploying to Flutter web |
    
- ***Implement basic Deep Linking in flutter***
    
    `Step 1: Add dependency`
    
    in `pubspec.yaml`
    
    ```dart
    dependencies:
      flutter:
        sdk: flutter
      uni_links: ^0.5.1
      
      // then run 
      flutter pub get
    ```
    
    `Step 2: Setup Native Config`
    
    ### Android (`android/app/src/main/AndroidManifest.xml`)
    
    Inside `<activity>` tag:
    
    ```dart
    <intent-filter>
        <action android:name="android.intent.action.VIEW"/>
        <category android:name="android.intent.category.DEFAULT"/>
        <category android:name="android.intent.category.BROWSABLE"/>
        <data
            android:scheme="myapp"
            android:host="profile"/>
    </intent-filter>
    ```
    
    ### iOS (`ios/Runner/Info.plist`)
    
    Add:
    
    ```dart
    <key>CFBundleURLTypes</key>
    <array>
      <dict>
        <key>CFBundleURLSchemes</key>
        <array>
          <string>myapp</string>
        </array>
      </dict>
    </array>
    ```
    
    `Step 3: Listen for Links in Flutter`
    
    `main.dart`
    
    ```dart
    import 'package:flutter/material.dart';
    import 'package:uni_links/uni_links.dart';
    import 'dart:async';
    
    void main() => runApp(MyApp());
    
    class MyApp extends StatefulWidget {
      @override
      State<MyApp> createState() => _MyAppState();
    }
    
    class _MyAppState extends State<MyApp> {
      String? _deepLink;
      StreamSubscription? _sub;
    
      @override
      void initState() {
        super.initState();
        initDeepLink();
      }
    
      Future<void> initDeepLink() async {
        try {
          final initialLink = await getInitialLink();
          setState(() => _deepLink = initialLink);
    
          _sub = linkStream.listen((String? link) {
            setState(() => _deepLink = link);
          });
        } catch (_) {}
      }
    
      @override
      void dispose() {
        _sub?.cancel();
        super.dispose();
      }
    
      @override
      Widget build(BuildContext context) {
        return MaterialApp(
          home: _deepLink == 'myapp://profile/123'
              ? ProfilePage(userId: '123')
              : HomePage(),
        );
      }
    }
    
    class HomePage extends StatelessWidget {
      @override
      Widget build(BuildContext context) => Scaffold(body: Center(child: Text('Home Page')));
    }
    
    class ProfilePage extends StatelessWidget {
      final String userId;
      ProfilePage({required this.userId});
    
      @override
      Widget build(BuildContext context) =>
          Scaffold(body: Center(child: Text('Profile Page for user $userId')));
    }
    ```
