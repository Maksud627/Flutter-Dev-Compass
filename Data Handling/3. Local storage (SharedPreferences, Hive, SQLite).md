- ***When to use which local storage?***
    
    
    | Storage Type | Use Case | Format | Pros |
    | --- | --- | --- | --- |
    | **SharedPreferences** | Small key-value pairs (login, theme, flags) | Key-Value | Simple, fast, built-in |
    | **Hive** | Complex objects, high-performance, offline cache | NoSQL | Fast, lightweight, no native dependencies |
    | **SQLite (sqflite)** | Relational structured data (tables) | SQL | Ideal for structured data & queries |
- ***SharedPreferences (Key-Value Store)***
    
    `add dependency`
    
    ```dart
    dependencies:
      shared_preferences: ^2.2.2
    ```
    
    `usage`
    
    ```dart
    import 'package:shared_preferences/shared_preferences.dart';
    
    void saveData() async {
      final prefs = await SharedPreferences.getInstance();
      await prefs.setString('username', 'alice');
      await prefs.setBool('isLoggedIn', true);
    }
    
    void loadData() async {
      final prefs = await SharedPreferences.getInstance();
      String? name = prefs.getString('username');
      bool? isLoggedIn = prefs.getBool('isLoggedIn');
      print(name); // alice
    }
    ```
    
- ***Hive (Fast NoSQL DB)***
    
    `add dependency`
    
    ```dart
    dependencies:
      hive: ^2.2.3
      hive_flutter: ^1.1.0
    
    dev_dependencies:
      hive_generator: ^2.0.1
      build_runner: ^2.4.6
    ```
    
    `initialize in main.dart`
    
    ```dart
    void main() async {
      WidgetsFlutterBinding.ensureInitialized();
      await Hive.initFlutter();
      Hive.openBox('myBox');
      runApp(MyApp());
    }
    ```
    
    `store/retrieve data`
    
    ```dart
    void saveHiveData() {
      var box = Hive.box('myBox');
      box.put('username', 'alice');
      box.put('isLoggedIn', true);
    }
    
    void loadHiveData() {
      var box = Hive.box('myBox');
      print(box.get('username')); // alice
    }
    ```
    
- ***SQLite***
    
    `sqflite package`
    
    `add dependency`
    
    ```dart
    dependencies:
      sqflite: ^2.3.2
      path: ^1.9.0
    ```
    
    `setup database`
    
    ```dart
    import 'package:sqflite/sqflite.dart';
    import 'package:path/path.dart';
    
    late Database db;
    
    Future<void> initDb() async {
      db = await openDatabase(
        join(await getDatabasesPath(), 'user_database.db'),
        onCreate: (db, version) {
          return db.execute(
            'CREATE TABLE users(id INTEGER PRIMARY KEY, name TEXT, email TEXT)',
          );
        },
        version: 1,
      );
    }
    ```
    
    `Insert, Query, Delete`
    
    ```dart
    Future<void> insertUser(String name, String email) async {
      await db.insert(
        'users',
        {'name': name, 'email': email},
        conflictAlgorithm: ConflictAlgorithm.replace,
      );
    }
    
    Future<void> getUsers() async {
      final List<Map<String, dynamic>> maps = await db.query('users');
      print(maps);
    }
    ```
    
- ***Summary***
    
    
    | Feature | SharedPreferences | Hive | SQLite |
    | --- | --- | --- | --- |
    | Format | Key-Value | Key-Value / Objects | Tables |
    | Use for | Small config values | Offline cache, objects | Relational data |
    | Native dependency | ❌ | ❌ | ✅ (platform-specific) |
    | Performance | Fast | Super fast | Moderate |
