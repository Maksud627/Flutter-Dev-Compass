- ***Buttons in Flutter***
    
    Flutter provides several button types, including:
    
    - `ElevatedButton` – Raised material-style button
    - `TextButton` – Flat text-only button
    - `OutlinedButton` – Bordered button
    - `IconButton` – Icon-based button
    - `FloatingActionButton` – Circular button (usually for primary action)
    
    ---
    
    ### 🔹 `ElevatedButton`
    
    ```dart
    ElevatedButton(
      onPressed: () {
        print('Elevated Button Clicked');
      },
      child: Text('Submit'),
    )
    
    ```
    
    You can customize it with `.styleFrom()`:
    
    ```dart
    ElevatedButton(
      style: ElevatedButton.styleFrom(
        backgroundColor: Colors.green,
        padding: EdgeInsets.symmetric(horizontal: 24, vertical: 12),
      ),
      onPressed: () {},
      child: Text('Save'),
    )
    
    ```
    
    ---
    
    ### 🔹 `TextButton`
    
    ```dart
    TextButton(
      onPressed: () {
        print('Text Button');
      },
      child: Text('Cancel'),
    )
    
    ```
    
    ---
    
    ### 🔹 `OutlinedButton`
    
    ```dart
    OutlinedButton(
      onPressed: () {},
      child: Text('More Info'),
    )
    
    ```
    
    ---
    
    ### 🔹 `IconButton`
    
    ```dart
    IconButton(
      icon: Icon(Icons.favorite),
      onPressed: () {
        print('Favorited');
      },
    )
    
    ```
    
    ---
    
    ### 🔹 `FloatingActionButton`
    
    Usually used in `Scaffold` for primary action:
    
    ```dart
    floatingActionButton: FloatingActionButton(
      onPressed: () {
        print('FAB tapped');
      },
      child: Icon(Icons.add),
    )
    
    ```
    
- ***Gesture Widgets***
    
    ### 🔹 `GestureDetector`
    
    Wrap any widget to make it interactive:
    
    ```dart
    GestureDetector(
      onTap: () {
        print('Container tapped!');
      },
      onLongPress: () {
        print('Long pressed!');
      },
      child: Container(
        width: 150,
        height: 150,
        color: Colors.blue,
        child: Center(child: Text('Tap Me')),
      ),
    )
    ```
    
    ### 🔹 `InkWell`
    
    Adds a ripple effect when tapping (used in Material apps):
    
    ```dart
    InkWell(
      onTap: () {
        print('Tapped with ripple!');
      },
      child: Container(
        padding: EdgeInsets.all(20),
        color: Colors.yellow,
        child: Text('Click Me'),
      ),
    )
    ```
    
    Use `InkWell` inside `Material` to show full ripple:
    
    ```dart
    Material(
      child: InkWell(
        onTap: () {},
        child: Padding(
          padding: EdgeInsets.all(16.0),
          child: Text('Ripple Text'),
        ),
      ),
    )
    ```
