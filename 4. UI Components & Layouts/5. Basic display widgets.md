- ***Text***
    
    ### 📌 What is it?
    
    `Text` displays a string of styled text in your app.
    
    ### 🧪 Basic Example:
    
    ```dart
    Text('Hello, Flutter!')
    ```
    
    ### 🎨 Styling Text:
    
    ```dart
    Text(
      'Styled Text',
      style: TextStyle(
        fontSize: 24,
        fontWeight: FontWeight.bold,
        color: Colors.blue,
        letterSpacing: 2,
        decoration: TextDecoration.underline,
      ),
    )
    ```
    
    ### ⚙️ Common Properties:
    
    - `style`: Apply `TextStyle` (font size, color, weight, etc.)
    - `textAlign`: Align text horizontally (`TextAlign.center`, etc.)
    - `maxLines`: Max number of visible lines
    - `overflow`: What to do if text is too long (`ellipsis`, `fade`, `clip`)
- ***Image***
    
    ### 📌 What is it?
    
    Displays images from assets, the internet, or memory.
    
    ### 🧪 From Asset:
    
    ```dart
    Image.asset('assets/images/flutter.png', width: 100)
    ```
    
    > ✅ Make sure to declare the image in pubspec.yaml.
    > 
    
    ### 🧪 From Network:
    
    ```dart
    Image.network(
      'https://flutter.dev/assets/homepage/carousel/slide_1-layer_0-2b4cb4c59f5a181f7b60d3980c0d5d09.png',
      width: 100,
    )
    ```
    
    ### 🧪 From Memory (Advanced):
    
    ```dart
    Image.memory(myImageBytes)
    ```
    
    ### ⚙️ Common Properties:
    
    - `width`, `height`
    - `fit`: How to fit the image (`BoxFit.cover`, `BoxFit.contain`, etc.)
    - `alignment`: Align within container
    - `color`: Apply tint
- ***Icon***
    
    ### 📌 What is it?
    
    `Icon` displays a Material or Cupertino icon.
    
    ### 🧪 Example:
    
    ```dart
    Icon(Icons.favorite, color: Colors.red, size: 40)
    ```
    
    > 🧩 All Material icons are under the Icons class.
    > 
    
    ### ⚙️ Common Properties:
    
    - `icon`: The icon to display (`Icons.home`, `Icons.star`)
    - `size`: Icon size
    - `color`: Icon color
    - `semanticLabel`: For accessibility

- ***Textfield***
    
    ### 📌 What is it?
    
    `TextField` allows the user to enter text.
    
    ### 🧪 Basic Example:
    
    ```dart
    TextField(
      decoration: InputDecoration(
        labelText: 'Enter your name',
        border: OutlineInputBorder(),
      ),
    )
    
    ```
    
    ### 🎯 With Controller:
    
    ```dart
    final TextEditingController _controller = TextEditingController();
    
    // In your widget:
    TextField(
      controller: _controller,
      decoration: InputDecoration(labelText: 'Your Name'),
    )
    
    ```
    
    You can get the input using:
    
    ```dart
    String name = _controller.text;
    
    ```
    
- ***Checkbox***
    
    ### 📌 What is it?
    
    A square box the user can check or uncheck.
    
    ### 🧪 Example:
    
    ```dart
    bool isChecked = false;
    
    Checkbox(
      value: isChecked,
      onChanged: (bool? newValue) {
        setState(() {
          isChecked = newValue!;
        });
      },
    )
    
    ```
    
    Use `CheckboxListTile` for label + checkbox:
    
    ```dart
    CheckboxListTile(
      title: Text("Accept Terms"),
      value: isChecked,
      onChanged: (bool? value) {
        setState(() {
          isChecked = value!;
        });
      },
    )
    
    ```
    
- ***Switch***
    
    ### 📌 What is it?
    
    A toggle switch (like turning something on/off).
    
    ### 🧪 Example:
    
    ```dart
    bool isSwitched = false;
    
    Switch(
      value: isSwitched,
      onChanged: (bool value) {
        setState(() {
          isSwitched = value;
        });
      },
    )
    
    ```
    
- ***Slider***
    
    ### 📌 What is it?
    
    Allows users to select a **value from a range**.
    
    ### 🧪 Example:
    
    ```dart
    double sliderValue = 10;
    
    Slider(
      min: 0,
      max: 100,
      value: sliderValue,
      onChanged: (double value) {
        setState(() {
          sliderValue = value;
        });
      },
    )
    
    ```
    
    You can also show the value using `Text('${sliderValue.toStringAsFixed(0)}')`.
    
- ***Radio & RadioListTile***
    
    ## 🔘 5. `Radio` & `RadioListTile`
    
    ### 📌 What is it?
    
    For selecting **one option out of a set**.
    
    ### 🧪 Example:
    
    ```dart
    String gender = 'male';
    
    RadioListTile<String>(
      title: Text('Male'),
      value: 'male',
      groupValue: gender,
      onChanged: (String? value) {
        setState(() {
          gender = value!;
        });
      },
    )
    
    ```
    
    ---
    
    ## 🧪 Full Example of Input Widgets:
    
    ```dart
    class InputWidgetsExample extends StatefulWidget {
      @override
      _InputWidgetsExampleState createState() => _InputWidgetsExampleState();
    }
    
    class _InputWidgetsExampleState extends State<InputWidgetsExample> {
      final TextEditingController _nameController = TextEditingController();
      bool _acceptTerms = false;
      bool _notifications = true;
      double _volume = 30;
      String _gender = 'male';
    
      @override
      Widget build(BuildContext context) {
        return Scaffold(
          appBar: AppBar(title: Text('Input Widgets')),
          body: Padding(
            padding: const EdgeInsets.all(16),
            child: Column(
              children: [
                TextField(
                  controller: _nameController,
                  decoration: InputDecoration(labelText: 'Your Name'),
                ),
                CheckboxListTile(
                  title: Text('Accept Terms'),
                  value: _acceptTerms,
                  onChanged: (val) => setState(() => _acceptTerms = val!),
                ),
                SwitchListTile(
                  title: Text('Enable Notifications'),
                  value: _notifications,
                  onChanged: (val) => setState(() => _notifications = val),
                ),
                Slider(
                  min: 0,
                  max: 100,
                  value: _volume,
                  label: 'Volume',
                  onChanged: (val) => setState(() => _volume = val),
                ),
                RadioListTile<String>(
                  title: Text('Male'),
                  value: 'male',
                  groupValue: _gender,
                  onChanged: (val) => setState(() => _gender = val!),
                ),
                RadioListTile<String>(
                  title: Text('Female'),
                  value: 'female',
                  groupValue: _gender,
                  onChanged: (val) => setState(() => _gender = val!),
                ),
              ],
            ),
          ),
        );
      }
    }
    
    ```
