| Type | Description |
| --- | --- |
| **Responsive** | The UI **adjusts size/layout** based on screen size (e.g., mobile vs. tablet vs. desktop). |
| **Adaptive** | The UI **adapts behavior/design** based on platform or device type (e.g., Android vs. iOS). |
- ***Basic responsive UI example***
    
    use of `MediaQuery`
    
    ```dart
    Widget build(BuildContext context) {
      final screenWidth = MediaQuery.of(context).size.width;
    
      return Scaffold(
        appBar: AppBar(title: Text('Responsive UI')),
        body: Center(
          child: screenWidth < 600
              ? Column(children: [Text('Mobile View')])
              : Row(children: [Text('Tablet/Desktop View')]),
        ),
      );
    }
    ```
    
- ***LayoutBuilder for responsive Widgets***
    
    `LayoutBuilder` gives constraints of the current widget
    
    ```dart
    LayoutBuilder(
      builder: (context, constraints) {
        if (constraints.maxWidth < 600) {
          return Text('Small screen');
        } else {
          return Text('Large screen');
        }
      },
    )
    ```
    
- ***Responsive Grid with*** `Wrap` or `GridView`
    
    ```dart
    GridView.count(
      crossAxisCount: MediaQuery.of(context).size.width > 600 ? 4 : 2,
      children: List.generate(10, (index) {
        return Card(child: Center(child: Text('Item $index')));
      }),
    )
    ```
    
- ***Adaptive design Example***
    
    ```dart
    import 'dart:io';
    
    Widget platformButton(VoidCallback onPressed) {
      return Platform.isIOS
          ? CupertinoButton(child: Text("Cupertino"), onPressed: onPressed)
          : ElevatedButton(child: Text("Material"), onPressed: onPressed);
    }
    ```
    
- ***Flutter’s built-in Adaptive Widgets***
    1. `Switch.adaptive`
    2. `CupertinoAlertDialog`
    3. `AppBar` can conditionally show Material or Cupertino
- ***Responsive Packages***
    1. `flutter_screenutil`
        
        ```dart
        // main.dart
        ScreenUtilInit(
          designSize: Size(375, 812), // iPhone X size
          builder: () => MyApp(),
        )
        
        // usage
        Container(
          width: 100.w,
          height: 50.h,
          child: Text('Scaled', style: TextStyle(fontSize: 16.sp)),
        )
        ```
        
    2. `responsive_builder`
        
        ```dart
        ScreenTypeLayout.builder(
          mobile: (_) => MobileView(),
          tablet: (_) => TabletView(),
          desktop: (_) => DesktopView(),
        );
        ```
        
- ***Summary***
    
    
    | Technique | When to Use |
    | --- | --- |
    | `MediaQuery` | For screen width/height |
    | `LayoutBuilder` | For local responsive widgets |
    | `ScreenUtil` | For scaling sizes/font dynamically |
    | `Platform.isIOS` | To switch behavior/UI for iOS vs Android |
    | `Switch.adaptive` | Automatically adjust for platform |
