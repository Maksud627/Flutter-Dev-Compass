- ***TextField***
    
    ### 🔹 Purpose:
    
    Used for user text input (like name, email, etc.).
    
    ### ✅ Basic Usage:
    
    ```dart
    TextField(
      decoration: InputDecoration(
        labelText: 'Enter your name',
        border: OutlineInputBorder(),
      ),
    )
    
    ```
    
    ### ✅ With Controller:
    
    ```dart
    final TextEditingController _controller = TextEditingController();
    
    TextField(
      controller: _controller,
      decoration: InputDecoration(labelText: 'Name'),
    )
    
    ```
    
    To get the text:
    
    ```dart
    String userName = _controller.text;
    
    ```
    
    ### 🔧 Common Properties:
    
    - `controller`: Tracks the value of the field.
    - `decoration`: Adds labels, borders, hints, icons, etc.
    - `keyboardType`: e.g. `TextInputType.number`
    - `obscureText`: `true` for passwords.
- ***Checkbox***
    
    ### 🔹 Purpose:
    
    For toggling a boolean value (checked/unchecked).
    
    ### ✅ Basic Example:
    
    ```dart
    bool isChecked = false;
    
    Checkbox(
      value: isChecked,
      onChanged: (bool? newValue) {
        setState(() {
          isChecked = newValue!;
        });
      },
    )
    
    ```
    
    ### ✅ With Label (`CheckboxListTile`):
    
    ```dart
    CheckboxListTile(
      title: Text("Accept Terms & Conditions"),
      value: isChecked,
      onChanged: (bool? value) {
        setState(() {
          isChecked = value!;
        });
      },
    )
    
    ```
    
    ### 🔧 Common Properties:
    
    - `value`: `true` or `false`
    - `onChanged`: Called when toggled
    - `activeColor`: Checkbox color when checked
    - `title`: (in `CheckboxListTile`) label text
- ***Radio***
    
    ### 🔹 Purpose:
    
    For selecting **one option out of many**.
    
    ### ✅ Basic Usage:
    
    ```dart
    String gender = 'male';
    
    Radio(
      value: 'male',
      groupValue: gender,
      onChanged: (String? value) {
        setState(() {
          gender = value!;
        });
      },
    )
    
    ```
    
    > groupValue connects multiple Radio buttons so only one is selected at a time.
    > 
    
    ### ✅ With Label (`RadioListTile`):
    
    ```dart
    RadioListTile<String>(
      title: Text('Male'),
      value: 'male',
      groupValue: gender,
      onChanged: (String? value) {
        setState(() {
          gender = value!;
        });
      },
    )
    
    ```
    
    You can repeat this for other options like `'female'`.
    
    ### 🔧 Common Properties:
    
    - `value`: The specific value of that radio button
    - `groupValue`: Currently selected value
    - `onChanged`: Callback on selection
