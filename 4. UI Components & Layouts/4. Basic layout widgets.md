## What are basic layout widgets?

- `Container`, `Row`, `Column`, `Expanded`, `Flexible`, `Wrap`, and `Stack` are considered some basic layout widgets.

- ***Container***
    
    ### 📦 What is it?
    
    `Container` is a box model widget. You can use it to:
    
    - Add **padding**, **margin**
    - Apply **background color**
    - Set **width**, **height**
    - Apply **borders**, **shadows**, and more.
    
    🧪 Example:
    
    ```dart
    Container(
      width: 200,
      height: 100,
      padding: EdgeInsets.all(16),
      margin: EdgeInsets.symmetric(vertical: 10),
      decoration: BoxDecoration(
        color: Colors.blue,
        borderRadius: BorderRadius.circular(12),
      ),
      child: Text(
        'Hello Container',
        style: TextStyle(color: Colors.white),
      ),
    )
    ```
    
    ✅ Useful when you want to visually style or size a widget.
    
- ***Row***
    
    ### ➡️ What is it?
    
    `Row` arranges its **children widgets horizontally**.
    
    ### 🧪 Example:
    
    ```dart
    Row(
      mainAxisAlignment: MainAxisAlignment.spaceEvenly,
      children: [
        Icon(Icons.home),
        Icon(Icons.star),
        Icon(Icons.settings),
      ],
    )
    ```
    
    ### 🔧 Common Properties:
    
    - `mainAxisAlignment`: Alignment along the horizontal (main) axis.
        - Values: `start`, `center`, `end`, `spaceAround`, `spaceBetween`, `spaceEvenly`
    - `crossAxisAlignment`: Alignment along the vertical (cross) axis.
        - Values: `start`, `center`, `end`, `stretch`
- ***Column***
    
    ### ⬇️ What is it?
    
    `Column` arranges its **children vertically**.
    
    ### 🧪 Example:
    
    ```dart
    Column(
      mainAxisAlignment: MainAxisAlignment.center,
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Text('Name: John'),
        Text('Age: 30'),
        ElevatedButton(onPressed: () {}, child: Text('Edit')),
      ],
    )
    ```
    
    🔁 `Row` and `Column` are often **nested** to build complex UIs.
    
- ***Expanded***
    
    ### 📌 What is it?
    
    `Expanded` takes up the **remaining available space** in a `Row`, `Column`, or `Flex`.
    
    ### ✅ Use it when:
    
    You want a widget to fill space **proportionally**.
    
    ### 🧪 Example:
    
    ```dart
    Row(
      children: [
        Expanded(child: Container(color: Colors.red, height: 50)),
        Expanded(child: Container(color: Colors.green, height: 50)),
      ],
    )
    ```
    
    🔍 Both containers will equally share the horizontal space.
    
- ***Flexible***
    
    ### 📌 What is it?
    
    Similar to `Expanded`, but **offers more control**. It allows the child to use **less** than the available space if it wants.
    
    ### 🧪 Example:
    
    ```dart
    Row(
      children: [
        Flexible(
          flex: 2,
          child: Container(color: Colors.orange, height: 50),
        ),
        Flexible(
          flex: 1,
          child: Container(color: Colors.purple, height: 50),
        ),
      ],
    )
    ```
    
    🎯 The orange container takes **2x** the space of the purple one.
    
- ***Wrap***
    
    ### 📌 What is it?
    
    `Wrap` lays out widgets **horizontally or vertically** and wraps to the next line if needed (like word wrap).
    
    ### ✅ Use it when:
    
    You need a dynamic layout that fits the screen (e.g., chips, tags).
    
    ### 🧪 Example:
    
    ```dart
    Wrap(
      spacing: 8,
      runSpacing: 4,
      children: List.generate(
        10,
        (index) => Chip(label: Text('Item $index')),
      ),
    )
    ```
    
    🧩 Wrap avoids overflow in horizontal space by **wrapping items** onto the next line.
    
- ***Stack***
    
    ### 📌 What is it?
    
    `Stack` allows **overlapping widgets**. Great for custom positioning.
    
    ### ✅ Use it for:
    
    - Banners
    - Avatars with status indicators
    - Tooltips
    - Floating elements
    
    ### 🧪 Example:
    
    ```dart
    Stack(
      children: [
        Container(
          width: 200,
          height: 200,
          color: Colors.blue,
        ),
        Positioned(
          top: 20,
          left: 20,
          child: Icon(Icons.star, color: Colors.white, size: 40),
        ),
      ],
    )
    ```
    
    📐 `Positioned` is used to place elements exactly within the Stack.
    
- ***When to use what?***
    
    
    | Widget | Use Case |
    | --- | --- |
    | `Expanded` | Fill remaining space in Row/Column |
    | `Flexible` | Fill space *flexibly* with a given `flex` |
    | `Wrap` | Layout that **flows onto multiple lines** |
    | `Stack` | **Overlapping widgets**, free positioning |
