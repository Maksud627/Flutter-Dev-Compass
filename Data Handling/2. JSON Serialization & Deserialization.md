- ***Serialization and Deserialization***
    
    
    | Term | Meaning |
    | --- | --- |
    | **Serialization** | Converting a Dart object → JSON (for sending to APIs) |
    | **Deserialization** | Converting JSON → Dart object (for displaying or storing data) |
- ***Example of a JSON data***
    
    ```json
    {
      "id": 1,
      "name": "Alice",
      "email": "alice@example.com"
    }
    ```
    
- ***Manual way of Serialization/Deserialization***
    
    `model`
    
    ```dart
    class User {
      final int id;
      final String name;
      final String email;
    
      User({required this.id, required this.name, required this.email});
    
      // Deserialization: JSON → Dart object
      factory User.fromJson(Map<String, dynamic> json) {
        return User(
          id: json['id'],
          name: json['name'],
          email: json['email'],
        );
      }
    
      // Serialization: Dart object → JSON
      Map<String, dynamic> toJson() {
        return {
          'id': id,
          'name': name,
          'email': email,
        };
      }
    }
    ```
    
    `usage code`
    
    ```dart
    // JSON string from API
    String jsonString = '{"id":1,"name":"Alice","email":"alice@example.com"}';
    
    // Decode JSON string to map
    Map<String, dynamic> jsonMap = jsonDecode(jsonString);
    
    // Deserialize
    User user = User.fromJson(jsonMap);
    
    // Serialize
    String backToJson = jsonEncode(user.toJson());
    ```
    
- ***Automatic way of Serialization/Deserialization***
    
    reducing boilerplate for large models using a package
    
    add this dependency in `pubspec.yaml`
    
    ```dart
    dependencies:
      json_annotation: ^4.8.1
    
    dev_dependencies:
      build_runner: ^2.4.6
      json_serializable: ^6.7.0
    ```
    
    `create model`
    
    ```dart
    import 'package:json_annotation/json_annotation.dart';
    
    part 'user.g.dart'; // Generated file
    
    @JsonSerializable()
    class User {
      final int id;
      final String name;
      final String email;
    
      User({required this.id, required this.name, required this.email});
    
      factory User.fromJson(Map<String, dynamic> json) => _$UserFromJson(json);
      Map<String, dynamic> toJson() => _$UserToJson(this);
    }
    ```
    
    `run code generator`
    
    ```dart
    flutter pub run build_runner build
    ```
    
    It generates `user.g.dart` with `_$UserFromJson` and `_$UserToJson` methods.
    
- ***When to use what?***
    
    
    | Approach | Use When |
    | --- | --- |
    | Manual | Simple models or learning phase |
    | json_serializable | Large/complex models, DRY code preferred |
