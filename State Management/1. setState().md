`setState` is a method used in **stateful widgets** to tell Flutter that **the internal state of the widget has changed** and that it **needs to rebuild** the UI to reflect that change.

- when setState() is called, it basically tells flutter,

"Hey Flutter, something has changed! Please redraw this widget with the new data.”

- `setState` triggers the `build` method to run again.
- Only the widget (and its subtree) that calls `setState` gets rebuilt — not the whole app.

```dart
class CounterPage extends StatefulWidget {
  @override
  _CounterPageState createState() => _CounterPageState();
}

class _CounterPageState extends State<CounterPage> {
  int counter = 0;

  void incrementCounter() {
    setState(() {
      counter++; // Update the counter variable
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: Text('Counter: $counter'),
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: incrementCounter, // Increments the counter
        child: Icon(Icons.add),
      ),
    );
  }
}
```
