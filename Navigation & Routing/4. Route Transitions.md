When you navigate from one screen to another using `Navigator.push()`, Flutter applies a **default slide-in animation** (from bottom on Android, from right on iOS).

Custom transitions let you control **how** the next screen appears — slide, fade, scale, rotate, etc.

- ***Default Navigation (No custom transition)***
    
    ```dart
    Navigator.push(
      context,
      MaterialPageRoute(builder: (context) => SecondPage()),
    );
    ```
    
- ***Custom Transition Using `PageRouteBuilder`***
    
    ```dart
    Navigator.push(
      context,
      PageRouteBuilder(
        pageBuilder: (context, animation, secondaryAnimation) => SecondPage(),
        transitionsBuilder: (context, animation, secondaryAnimation, child) {
          const begin = Offset(1.0, 0.0); // start from right
          const end = Offset.zero;
          const curve = Curves.ease;
    
          final tween = Tween(begin: begin, end: end).chain(CurveTween(curve: curve));
          final offsetAnimation = animation.drive(tween);
    
          return SlideTransition(position: offsetAnimation, child: child);
        },
      ),
    );
    ```
    
- ***Types of Transitions***
    - *Slide Transition*
        
        ```dart
        SlideTransition(
          position: animation.drive(Tween(begin: Offset(1, 0), end: Offset.zero)),
          child: child,
        )
        ```
        
    - *Fade Transition*
        
        ```dart
        FadeTransition(
          opacity: animation,
          child: child,
        )
        ```
        
    - *Scale Transition*
        
        ```dart
        ScaleTransition(
          scale: animation,
          child: child,
        )
        ```
        
    - *Rotation + Scale Transition*
        
        ```dart
        RotationTransition(
          turns: animation,
          child: ScaleTransition(scale: animation, child: child),
        )
        ```
        
- ***Implementation of route with a Fade Transition***
    
    ```dart
    Navigator.push(
      context,
      PageRouteBuilder(
        pageBuilder: (_, __, ___) => SecondPage(),
        transitionsBuilder: (_, animation, __, child) {
          return FadeTransition(
            opacity: animation,
            child: child,
          );
        },
      ),
    );
    ```
    
- ***Reusable Custom Route***
    
    `create a reusable route class`
    
    ```dart
    class FadeRoute extends PageRouteBuilder {
      final Widget page;
      FadeRoute({required this.page})
          : super(
              pageBuilder: (_, __, ___) => page,
              transitionsBuilder: (_, animation, __, child) =>
                  FadeTransition(opacity: animation, child: child),
            );
    }
    ```
    
    `Then use it like this:`
    
    ```dart
    Navigator.push(context, FadeRoute(page: SecondPage()));
    ```
    
- ***Summary***
    
    
    | Transition | Widget Used |
    | --- | --- |
    | Slide | `SlideTransition` |
    | Fade | `FadeTransition` |
    | Scale | `ScaleTransition` |
    | Rotate | `RotationTransition` |
    | Custom | Combine above in `PageRouteBuilder` |
