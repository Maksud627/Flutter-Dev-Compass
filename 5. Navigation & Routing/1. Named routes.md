— Named routes allow you to **navigate between screens using string identifiers** rather than directly creating widgets.

**Beneficial for**:

1. Keeping code organized
2. Navigating easily between screens
3. Managing deep links or nested navigation

- ***Basic setup for Named Routes***
    
    `*defining screens (pages)*`
    
    ```dart
    // home_screen.dart
    import 'package:flutter/material.dart';
    
    class HomeScreen extends StatelessWidget {
      @override
      Widget build(BuildContext context) {
        return Scaffold(
          appBar: AppBar(title: Text('Home')),
          body: Center(
            child: ElevatedButton(
              child: Text('Go to About'),
              onPressed: () {
                Navigator.pushNamed(context, '/about');
              },
            ),
          ),
        );
      }
    }
    
    // about_screen.dart
    class AboutScreen extends StatelessWidget {
      @override
      Widget build(BuildContext context) {
        return Scaffold(
          appBar: AppBar(title: Text('About')),
          body: Center(
            child: ElevatedButton(
              child: Text('Back'),
              onPressed: () {
                Navigator.pop(context);
              },
            ),
          ),
        );
      }
    ```
    
    `*register routes in MaterialApp*`
    
    ```dart
    void main() {
      runApp(MaterialApp(
        initialRoute: '/',
        routes: {
          '/': (context) => HomeScreen(),
          '/about': (context) => AboutScreen(),
        },
      ));
    }
    ```
    
    `*navigate between named routes*`
    
    ```dart
    Navigator.pushNamed(context, '/about');   // Go to About
    Navigator.pop(context);                  // Go back
    ```
    
- ***Passing arguments in Named Routes***
    
    `Step 1 : Navigate with arguments` 
    
    ```dart
    Navigator.pushNamed(
      context,
      '/profile',
      arguments: 'John Doe',
    );
    ```
    
    `Step 2: Access arguments in the destination screen`
    
    ```dart
    class ProfileScreen extends StatelessWidget {
      @override
      Widget build(BuildContext context) {
        final String name = ModalRoute.of(context)!.settings.arguments as String;
    
        return Scaffold(
          appBar: AppBar(title: Text('Profile')),
          body: Center(child: Text('Hello, $name')),
        );
      }
    }
    ```
    
    `Step 3: Register in routes`
    
    ```dart
    routes: {
      '/profile': (context) => ProfileScreen(),
    }
    ```
